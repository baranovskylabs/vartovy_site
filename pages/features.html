Features

Vartovy як security platform: детально

Це більше, ніж менеджер паролів: модульна платформа для захисту критичних цифрових активів з офлайн-надійністю і прогнозованими security-сценаріями.

Платформна архітектура

Кожен модуль вирішує окремий клас ризиків, але працює в єдиному security-контурі.

🧠

Security Core

Staged unlock, policy lockout, сесійні правила і керування доступом на рівні застосунку.

🗄️

Storage Layer

Шифроване локальне сховище, контроль цілісності та режим виділеного знімного носія.

🩺

Reliability Center

Операційні сигнали ризику: слабкі/повторні/прострочені записи, стан бекапів і recovery readiness.

🚨

Recovery Center

Paper kit, recovery-code, checklist і тренування аварійного доступу до інциденту.

⛓️

Audit Chain

Tamper-evident аудит дій з перевіркою ланцюжка цілісності для доказової надійності.

📐

Policy Engine

Єдині правила рішень для модулів без фрагментації логіки і суперечностей у поведінці.

🗄️ Що можна захищати

Vartovy покриває ширший клас критичних цифрових активів, а не тільки credentials.

🔑

Паролі та облікові дані

Логін, пароль, URL, нотатка, TOTP-ключ — всі поля в одному записі. Пошук по всьому сейфу миттєвий навіть для тисяч записів.

🗒️

Захищені нотатки

Seed-фрази, PIN-коди, приватні нотатки, ліцензійні ключі. Зберігаються зашифровано — як і всі інші записи.

📎

Файлові вкладення

Документи, скани, SSH/PGP ключі, сертифікати — прямо до запису. Шифруються разом із вмістом сейфа.

💳

Банківські картки

Спеціальний тип для платіжних карток: номер, CVV, строк дії. Без хмарного посередника.

🪪

Особисті документи

Паспорт, ІПН, закордонний паспорт, страховий поліс — у структурованому вигляді, не як "захищена нотатка".

🔐

SSH / API ключі

Окремий тип для ключів розробника: приватні ключі, токени, webhook secrets. Копіювання в один клік без ризику випадкового відображення.

🔒 Рівні захисту і доступу

Ви вирішуєте, що і наскільки строго захищати.

🧠

Майстер-пароль (Argon2id)

Пароль ніколи не зберігається — з нього виводиться ключ шифрування через Argon2id з адаптивними параметрами. Без пароля файл сейфа марний.

🔢

PIN-код

Короткий PIN для зручного розблокування після першого входу. PIN кешує сесію на час, що ви вкажете — не замінює майстер-пароль.

✋

Windows Hello

Відбиток пальця або обличчя через Windows Hello. Біометричні дані залишаються в захищеному анклаві Windows — Vartovy їх не бачить і не зберігає.

⬛

Графічний ключ

Малюйте патерн замість символів — зручно на сенсорних екранах або коли поруч чужі очі.

⏱️

Автоблокування

Автоматично блокується після часу бездіяльності або при згортанні вікна. Від 30 секунд до ніколи.

🚫

Захист від підбору

Наростаюча затримка після невдалих спроб. Опціонально — повний lockout з вимогою recovery-коду.

🛡️ Шифрування на кожному рівні

Тільки перевірені стандарти — жодних власних алгоритмів.

🔐

AES-256-GCM

Кожен запис і вкладення шифруються з унікальним nonce. GCM-режим автентифікує дані — підробка виявляється при відкритті.

🧂

Argon2id

Переможець PHC Password Hashing Competition. Memory-hard алгоритм — brute-force на файл сейфа практично нездійсненний навіть на GPU-кластерах.

✍️

Ed25519 для ліцензій

Pro-ключі підписані Ed25519. Десктоп верифікує підпис локально — без сервера. Офлайн-верифікація працює завжди.

🔄 Відновлення і резервні копії

Якщо щось піде не так — ваші дані залишаться з вами.

🗝️

Recovery-код без бекдору

При створенні сейфа генерується recovery-код. У розробника немає резервної копії. Якщо втратите і пароль, і код — дані будуть недоступні. Це не баг — це гарантія вашої приватності.

💾

Зашифрований бекап

Експортуйте сейф у зашифрований файл — збережіть на флешку, у холодне сховище. Файл відкривається лише майстер-паролем.

📤

Імпорт і міграція

Переїжджаєте з іншого менеджера? Vartovy підтримує імпорт з популярних форматів CSV/JSON. Є і зворотній експорт.

📋

Журнал і цілісність подій

Локальна стрічка активності з верифікацією audit chain: входи, зміни записів, невдалі спроби, backup/recovery дії.
